# Regression corpus

Every `.txt` here is an input sequence run by `make smoke`.

    FALLOUT_TEST_MODE=1 timeout 120 python3 fallout_prequel.py < seq.txt

One input per line. No comments — the game reads these verbatim.

## Sequences are positional

A line lands wherever the game next reads. One extra or missing line
and everything after it lands on the wrong prompt. Symptom: the
character ends up named `1`.

Known offsets in the current build:

- **The title screen loops 3 times.** Three bare Enters before the
  name prompt.
- Then: name (free text), 3 stat increases, 1 trait, 1 weapon.
- After that, alternating `pause()` Enters and menu numbers.

`golden-path.txt` is a verified starting point — it reaches character
creation correctly. It does not survive to the ending (the choices it
makes lead to a death), which is a legitimate outcome but makes it a
weak golden path. **Replacing it with a survivable full-playthrough
sequence is a good first issue.**

## What lives here

1. **Golden path** — the intended playthrough. Fixed. Never
   regenerated by an agent.
2. **Minimised crash reproducers** — from the Playtester, promoted
   here once minimised and re-verified.

The second kind is why the Playtester is worth building. A crash
found once and fixed is worth little; a crash found once and guarded
forever is worth a lot.
