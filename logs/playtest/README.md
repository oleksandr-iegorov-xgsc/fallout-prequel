# Playtest notes

## Human notes — `YYYY-MM-DD.md`

Ten minutes after a run. The highest-signal input in this system and
the one thing no agent can produce — SOUL.md's pillars are about felt
experience, and only you have any.

Write down: where the dread landed and where it didn't, what you
skimmed, which choice felt fake, what you expected to matter and
didn't, whether the ending earned itself.

Write observations, not suggestions. The suggestions are the easy
part and you'll produce better ones later, from these notes.

## `generated/`

Playtester output — sequences and transcripts, paired by filename.
Disposable. Anything worth keeping gets promoted to `tests/scripts/`.
